## 🚀 Flujo de Trabajo y Reglas de Oro

1. **Consulta inicial**: Toda tarea debe alinearse con [GOLDEN_RULES.md](GOLDEN_RULES.md) y [AGENT_CURATION_SOP.md](AGENT_CURATION_SOP.md).
2. **Validación continua**: Cada cambio debe superar `npm run typecheck && npm run validate:taxonomy && npm test`.
3. **Despliegue blindado**: `npm run deploy` para verificación multi-anillo antes de sincronizar con GitHub y Cloudflare Workers.
