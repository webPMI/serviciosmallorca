# 🌍 Internacionalización (i18n) - WebApp Starter

> **Dominio del Agente Frontend (`@frontend`)**

## Idiomas Soportados

| Código | Nombre  | Bandera      |
| ------ | ------- | ------------ |
| `es`   | Español | 🇪🇸 (default) |
| `en`   | English | 🇬🇧           |
| `ca`   | Català  | 🇦🇩           |
| `de`   | Deutsch | 🇩🇪           |

## Flujo de Detección

```
1. Cookie 'locale' (establecida por el middleware o el usuario)
   ↓ (si no existe)
2. Cabecera Accept-Language del navegador
   ↓ (si no coincide)
3. Default: 'es' (Español)
```

## Middleware (`src/middleware.ts`)

```typescript
// 1. Si la URL ya tiene un locale válido → guardar cookie y seguir
if (firstSegment && LOCALES.includes(firstSegment)) {
  cookies.set("locale", firstSegment, { maxAge: 365 días });
  return next();
}

// 2. Si es la raíz → redirigir al locale detectado
if (pathname === "/") {
  const detected = detectUserLocale(request);
  return redirect(`/${detected}/`, 302);
}
```

## Archivos de Traducción

- `src/i18n/es.json` - Español (idioma base)
- `src/i18n/en.json` - English
- `src/i18n/ca.json` - Català
- `src/i18n/de.json` - Deutsch

**Regla**: Las claves deben existir en los 4 archivos con el mismo nombre. Los tests verifican la paridad de claves automáticamente.

## Uso en Componentes

```astro
---
import { getLocaleFromUrl, loadTranslations, getLangPrefix } from "../../i18n";

const locale = getLocaleFromUrl(Astro.url);
const translations = await loadTranslations(locale);
---

<h1>{translations["home.heading"]}</h1>
```

## Añadir Nuevas Traducciones

1. Añadir la clave a `es.json` (idioma base)
2. Añadir la misma clave a `en.json`, `ca.json` y `de.json`
3. Los tests (`i18n.test.ts`) verificarán automáticamente la paridad

## Patrón de Claves

- `site.*` - Strings globales (title)
- `nav.*` - Navegación
- `home.*` - Homepage
- `auth.*` - Formularios de autenticación
- `dashboard.*` - Dashboard
- `footer.*` - Footer
- `legal.*` - Páginas legales
- `theme.*` - Sistema de temas

## API de Utilidades (`src/i18n/index.ts`)

| Función                     | Descripción                    |
| --------------------------- | ------------------------------ |
| `getLocaleFromUrl(url)`     | Extrae el locale de la URL     |
| `loadTranslations(locale)`  | Carga las traducciones (async) |
| `getLangPrefix(locale)`     | Retorna `/[locale]/`           |
| `detectUserLocale(request)` | Detecta el locale del usuario  |
| `getLocalizedUrl(locale)`   | Genera URL localizada          |

## Reglas del Agente Frontend para i18n

- ✅ Toda cadena visible usa `translations["key"]`
- ✅ Las claves existen en los 4 JSON
- ✅ Usar dot notation para organización
- ❌ No hardcodear texto en el markup
- ❌ No crear claves nuevas solo en un idioma
